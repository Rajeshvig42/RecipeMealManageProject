# Recipe and Meal Planning App (with EJS)

This backend uses EJS templates for rendering frontend pages.

## Tech Stack
- Node.js
- Express.js
- MongoDB (Mongoose)
- EJS
- JWT Authentication

## Getting Started
1. Clone the repo
2. Run `npm install`
3. Create a `.env` file (example below)
4. Run `npm run dev` to start in development mode

## Example .env
```
MONGO_URI=your_mongo_connection_string
JWT_SECRET=your_secret_key
NODE_ENV=development
PORT=5000
```
